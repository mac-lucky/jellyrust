# v0.12.0 - No reporting code at all

JellyRust 0.11.0 already sent nothing: no reporting endpoint was compiled in. This release removes the code itself. The crash-reporting and analytics clients inherited from Native Jelly, the questions that ask for them and the crash-upload helper the package carried are gone, so there is nothing left to switch on.

## What's new

- **No crash reporting or analytics code.** Sentry crash reports, PostHog usage analytics, the report queue and the first-run question about them are removed, and the package no longer ships the `sentry-crash` helper. A crash is still written to the local crash log on the TV, and the only server JellyRust talks to is your Jellyfin server.
- **Settings > Privacy & data** now holds what this app actually has: what is stored on this TV, and **Delete all local data**, which still also removes any report files an older Native Jelly install left behind.

## Fixed

- **The privacy policy's first heading said "Native Jelly".** It now names JellyRust, in all five languages, and the open-source notice no longer lists components the app does not ship.

## Compatibility

Watched by hand with this build on an LG C5 (2025, webOS 10.3.1): signed in with Quick Connect and played a film directly. The LG C1 (2021, webOS 6.5.3) was watched with v0.11.0, including a DTS film the server transcodes; in the player this release only removes reporting calls. On every other firmware the app is only known to pass webosbrew's static compatibility check, which this release ran on its package. If you try it on another set, please [report what happened](https://github.com/mac-lucky/jellyrust/issues), whether it worked or not.

## Known issues

- **Never type a password into the app.** It logs keys and typed text to `/tmp` on the TV. Sign in with Quick Connect from another device instead.
- **The long-pause fix from v0.11.0 has not yet been re-tested on a television** with a real pause into the screen saver.
- **Native Jelly 0.10.0's known issues were not re-checked for this fork.**

## Installing

Download **com.macluckylab.jellyrust_0.12.0_arm.ipk** and install it with the [Homebrew Channel](https://github.com/webosbrew/webos-homebrew-channel) or [dev-manager-desktop](https://github.com/webosbrew/dev-manager-desktop). You do **not** need a rooted TV.

Nothing in this distribution chain is signed, so this sha256 is what tells you the file you have is the file published here:

```
__IPK_SHA256__  com.macluckylab.jellyrust_0.12.0_arm.ipk
```
