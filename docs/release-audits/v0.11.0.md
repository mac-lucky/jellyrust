## External compatibility reports known at release time

None. This is JellyRust's first release.

## Compatibility tiers, and what moved

The C1 on webOS 6.5.3 is the only set with watched playback. Every other firmware rests on the static webosbrew-ipk-verify check generated below; a static check never moves a playback line. Native Jelly's own device evidence belongs to its builds, not to this fork's.

## Known issues at release, with provenance

- Typed text, including a password, is logged to `/tmp` on the television: the input path is upstream's and unchanged. Sign in with Quick Connect.
- The long-pause restart (a reconnect Range answered 200 restarts the transcode at the playhead) was reproduced and fixed against the C1 and has not been re-tested with a real pause since.
- Native Jelly 0.10.0's known issues were not re-checked for this fork.

## Deliberately not done

- No telemetry: `telemetry/sender.rs` compiles no Sentry or PostHog endpoint, the release workflow builds with `telemetry: none`, and no debug files are uploaded anywhere.
- No nightly builds and no project website: `nightly.yml` and `pages.yml` are disabled in the repository settings.
- The Plex code paths inherited from PlxNative stay in the source but are not reachable: `catalog/account.rs` and `catalog/discover.rs` refuse plex.tv and Plex's metadata provider.

## Release configuration

| | |
|---|---|
| flavour | `com.macluckylab.jellyrust` (stable) - the id users install; `FLAVOR: stable` is pinned in the release workflow's build job |
| cargo features | `RELEASE=1`, which drops `devtools` and `devtriggers` |
| telemetry | `none`: no endpoint compiled in, no Sentry upload |
| built by | GitHub Actions, from the tag, at a path identical on every runner |
| toolchain | webOS NDK and Rust nightly as pinned by the workflows, unchanged from Native Jelly 0.10.0 |

A new app id, `com.macluckylab.jellyrust`, with its storage helper `com.macluckylab.jellyrust.storage` and DB8 kind `com.macluckylab.jellyrust.storage:1`; nothing is written outside the app's own directories. The only outbound host is the user's Jellyfin server.
