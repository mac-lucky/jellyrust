The evidence behind [the v0.12.0 release note](https://github.com/mac-lucky/jellyrust/blob/main/docs/release-notes/v0.12.0.md). ## External compatibility reports known at release time

None.

## Compatibility tiers, and what moved

The C5 on webOS 10.3.1 moves to watched playback: a first for this set, which before this release only reached the sign-in screen. The C1 on webOS 6.5.3 keeps its v0.11.0 evidence. Every other firmware rests on the static webosbrew-ipk-verify check generated below; a static check never moves a playback line.

## Known issues at release, with provenance

- Typed text, including a password, is logged to `/tmp` on the television: the input path is upstream's and unchanged. Sign in with Quick Connect.
- The long-pause restart (a reconnect Range answered 200 restarts the transcode at the playhead) was reproduced and fixed against the C1 and has not been re-tested with a real pause since.
- Native Jelly 0.10.0's known issues were not re-checked for this fork.

## Deliberately not done

- No telemetry, now as an absence of code: the Sentry and PostHog clients, the report queue and spool, the consent screens, the sign-in "Send report" lane, the usage-event schema and the Sentry Native `sentry-crash` handler were deleted. The local crash log (`src/crashtrace.c`, with the `img:` marker now in `rust-modules/src/crashlog.rs`) and the event log stay.
- The storage helper still reads an old consent record if an earlier install left one; dropping it from the stored format is a separate, versioned change.
- No live stack sampler: `tools/nativejelly-sample` and its ARM helper were built on the Sentry Native tree's libunwind and went with it.
- No nightly builds and no project website: `nightly.yml` and `pages.yml` are disabled in the repository settings.

## Release configuration

| | |
|---|---|
| flavour | `com.macluckylab.jellyrust` (stable) - the id users install; `FLAVOR: stable` is pinned in the release workflow's build job |
| cargo features | `RELEASE=1`, which drops `devtools` and `devtriggers` |
| telemetry | none: no reporting code is compiled in, and the package ships no crash-upload helper |
| built by | GitHub Actions, from the tag, at a path identical on every runner |
| toolchain | webOS NDK and Rust nightly as pinned by the workflows, unchanged from v0.11.0 |

Same app id as v0.11.0, `com.macluckylab.jellyrust`, with its storage helper `com.macluckylab.jellyrust.storage` and DB8 kind `com.macluckylab.jellyrust.storage:1`, so an update keeps the sign-in. Nothing is written outside the app's own directories. The only outbound host is the user's Jellyfin server.
